# Android (K-094)

Salinan skrip pembuat APK Saku Pajak. Skrip ini dijalankan dari folder kerja di luar repo,
`%USERPROFILE%\SakuPajak-android\`, yang berisi pustaka `@bubblewrap/core` 1.27.0, folder `sdk\`
(junction ke Android SDK), proyek Android hasil generator, dan hasil APK.

Kunci tanda tangan, kata sandinya, dan berkas APK tidak pernah masuk repo ini. Panduan lengkapnya
ada di `docs/ANDROID.md`.
